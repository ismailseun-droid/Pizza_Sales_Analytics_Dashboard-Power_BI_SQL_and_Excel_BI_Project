# Pizza_Sales_Analytics_Dashboard-Power_BI_SQL_and_Excel_BI_Project

(1) 📌 **Pizza Sales Analytics Dashboard: End-to-End Business Intelligence Project**
An end-to-end analytics project that leverages SQL, Excel, and Power BI to transform raw pizza sales transactions into actionable business insights through KPI reporting, trend analysis, product performance evaluation, and interactive dashboarding.

---
(2) 🎯 **Project Purpose**
The objective of this project was to analyze pizza sales performance and develop interactive dashboards that enable stakeholders to monitor revenue, customer ordering behavior, product performance, and sales trends.
The project demonstrates the complete analytics workflow from data extraction and SQL analysis to dashboard development and business recommendations.

---
(3) 🛠️ **Tech Stack**
The project was built using the following tools and technologies:
🗄️ SQL:
Data exploration, KPI calculations, Trend analysis, Product performance analysis, Business insight generation

-Interactive dashboard development -Data modeling -DAX measures -KPI reporting -Business visualization

(4) 📂 **Data Source**
Source Dataset
Dataset obtained from: https://drive.google.com/drive/folders/17U0ah6Q4MJM_wIn_Xl4fHc-1fO6Q4s6z

Dataset Description
The dataset contains pizza sales transaction records captured throughout 2015.
Key fields include: Order ID, Order Date, Order Time, Pizza Name, Pizza Category, Pizza Size, Quantity Sold, Unit Price, Total Price
Dataset Summary: 48,620 transaction records, 21,350 customer orders, Multiple pizza categories, Multiple pizza sizes, one full year of sales activity

🚀 **Project Workflow**
Raw Sales Data ⬇️ SQL Data Analysis ⬇️ Data Cleaning & Transformation ⬇️ Excel Dashboard Development ⬇️ Power BI Dashboard Development

---
(5) 📊 **Dashboard Features & Highlights**
💰 Executive KPI Dashboard
Tracks key business metrics including: Total Revenue, Average Order Value, Total Orders, Total Pizzas Sold, Average Pizzas per Order
📅 Sales Trend Analysis
Provides visibility into: Daily ordering patterns, Monthly sales trends, Seasonal fluctuations, Peak demand periods
🍕 Product Performance Analysis
Identifies: Best-selling pizzas, Worst-selling pizzas, Top revenue-generating products, Product demand patterns
📦 Category Analysis
Analyzes: Sales by pizza category, Revenue contribution by category, Category performance rankings
📏 Size Analysis
Evaluates: Revenue contribution by pizza size, Customer size preferences, Size-based sales distribution

🗄️SQL Analysis
SQL was used to perform exploratory data analysis and business performance analysis before dashboard development.
KPI Analysis
The following KPIs were calculated using SQL: Total Revenue, Average Order Value, Total Orders, Total Pizzas Sold, and Average Pizzas Per Order
Trend Analysis
SQL queries were developed to analyze: Daily Order Trends, Monthly Order Trends, Sales by Pizza Category, and Sales by Pizza Size
Product Performance Analysis
Additional SQL queries identified: Top 5 Pizzas by Revenue, Bottom 5 Pizzas by Revenue, Top 5 Pizzas by Quantity Sold, Bottom 5 Pizzas by Quantity Sold, Top 5 Pizzas by Total Orders, Bottom 5 Pizzas by Total Orders
The SQL analysis formed the foundation for the Power BI and Excel dashboard visualizations.

🔍 **Key Business Insights**
💵 Revenue Performance - Total Revenue generated: $817.86K, Average Order Value: $38.31, Average Pizzas per Order: 2.32
📅 Customer Ordering Patterns - Fridays generated the highest order volume; weekends consistently experienced higher demand; July recorded the highest monthly order volume.
🍕 Product Performance - Top Revenue Generators (Thai Chicken Pizza, Barbecue Chicken Pizza), Lowest Revenue Generators(Brie Carre Pizza, Green Garden Pizza)
📏 Size Insights - Large pizzas generated approximately 46% of total revenue, and Medium pizzas accounted for approximately 30%
💡 **Business Recommendations**
1️⃣ Optimize Peak-Day Operation: Increase staffing and inventory levels on Fridays and Saturdays to meet elevated demand.
2️⃣ Promote High-Performing Products: Feature top-selling pizzas in marketing campaigns and promotional bundles.
3️⃣ Improve Low-Performing Products: Review pricing, ingredients, and marketing strategies for underperforming menu items.
5️⃣ Seasonal Marketing Initiatives: Develop promotional campaigns during lower-performing months to smooth demand throughout the year.
